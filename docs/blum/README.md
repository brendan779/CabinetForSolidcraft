# Blum reference

Facts taken from the Blum *Catalogue and technical manual 2024/2025* (English). The catalogue
itself stays local in `vendor-cad/blum/catalogue/` (PDF page = printed page + 4) and is never
committed.

- [webcodes.csv](webcodes.csv): every web code the catalogue prints, the product it names, and
  the printed pages it appears on. `family` is our grouping by the catalogue's page ranges, not a
  Blum field. Rows with no product name are codes printed on overview pages without a title.
